02Exportar como imagen

Cualquiera de las tres opciones te da un PNG a alta resolución listo para usar.

A · Snipping Tool

Win + Shift + S, encuadras solo la card (sin el header/footer) y guardas. Rápido y 1:1.

B · DevTools node screenshot

Abre con F12, en Elements busca id="mark-dark" (o el que quieras), click derecho → Capture node screenshot. Sale exportado sin escalado, con transparencia posible.

C · Zoom + captura

Zoom del navegador Ctrl + + hasta que ocupe la pantalla, luego captura completa. Ideal si necesitas un PNG grande para print.

03Guidelines de uso

Reglas mínimas para que la marca aguante en cualquier contexto y no se degrade.

Safe area
Deja alrededor al menos el ancho de la "S" en espacio libre. Nada de logos, texto o bordes tocándola.
Tamaño mínimo
32 px de alto en pantalla. Por debajo la ligadura del script se aplasta y pierde legibilidad.
Color
Solo negro (#0b0b0b) o crema (#f5f2ee). No aplicar el acento vermilion al glifo mismo — es acento del sistema, no del logo.
Fondo
Blanco puro (#ffffff) o negro warm (#0b0b0b). Evitar gradientes o fotos detrás del glifo.
No inclinar / distorsionar
Nunca oblicua o extiendas. Si necesitas otra proporción, usa la variante Wordmark.
No añadir sombra
La marca es plana, editorial. Sombras la vuelven web 2.0 y le quitan permanencia.

04Siguiente paso — vectorizar

Para que sea marca real (ownable, sin depender de Google Fonts), convierte el PNG a vector SVG:

Opción A · Figma

Pega la "S" en Figma con font Great Vibes, click derecho → Outline stroke / Flatten. Ahora es un shape editable. Export SVG.

Opción B · Inkscape (gratis)

Import el PNG → Path → Trace Bitmap. Ajusta threshold hasta que salga limpio. Export como SVG optimizado.

Opción C · Redibujar

La forma es simple — con Bézier en Figma/Illustrator sacas una versión "tuya" en 20 min. Recomendado si es marca oficial de largo plazo.
